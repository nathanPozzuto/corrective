This is our Steelhacks 2026 Project. The team consisted of Nathan Pozzuto, Arjay Gralewski-Goel (GitHub Link), and Finn Petz (GitHub Link).

As of 9/19/26, the website does not support profile creation for personalization. For now, the website shows how the UI will look and function.
Additionally, we will definitely have to make some optimizations because the website runs very slowly.
