Recovery Tracker — Backend API

Spring Boot service backing the workout & recovery tracker. The static frontend in ../frontend talks to these endpoints.

Run it

cd backend
# Neon credentials are read from PGHOST / PGDATABASE / PGUSER / PGPASSWORD
export PGHOST=... PGDATABASE=... PGUSER=... PGPASSWORD=...
export AI_GATEWAY_API_KEY=...   # optional, enables handout scanning
mvn spring-boot:run

The API starts on http://localhost:8080. Then open ../frontend/index.html in a browser (or serve the folder), and it will connect automatically.

Auth

Email + password. Sign-in returns a token; send it as Authorization: Bearer <token> on every request. All data is scoped to the authenticated user.
